# My Skills

我制作并持续改进的 AI 技能合集。

## 几何拼贴海报

将照片转化为几何色块组成的海报，保留原图的主体构图、主要配色与空间层次。

技能文件：[geometric-collage-poster](skills/geometric-collage-poster/SKILL.md)

### 能做什么

- 保留主体位置、相对大小、前后关系和画幅比例。
- 用矩形、梯形、三角形和不规则多边形概括画面。
- 天空、水面等连续区域优先使用完整的大色块，减少无必要的三角切分。
- 用几何切面和明暗色块保留必要的体积感。
- 默认生成一张无文字、无边框的海报。

### 适合的图片

风景、街景、建筑、静物和产品照片。

目前已用海边小屋、海湾汽车和冰箱饮料瓶照片进行人工效果测试。其他题材的表现仍需继续验证。

### 使用条件

需要能够读取图片和技能文件、并具备图像生成或编辑工具的 AI 环境。

本仓库提供工作指令，不包含图像生成模型或 API 密钥。实际生成能力、费用和限制取决于使用的平台。

### 如何使用

#### 方法一：下载后试用

适合先体验一次效果的用户。

1. 点击仓库首页的 **Code → Download ZIP**，下载并解压。
2. 打开 `skills/geometric-collage-poster` 文件夹，找到 `SKILL.md`。
3. 将 `SKILL.md` 和想转换的图片一起上传到支持文件读取和图像编辑的 AI 工具。
4. 发送：“请按照附件 SKILL.md 的规则，将这张图片转换为几何拼贴海报。”

这种方式是单次提供规则，不会自动安装技能。

#### 方法二：安装到 Codex

适合希望反复使用的 Codex 用户。

在 Codex 输入框发送以下内容：

> 请使用 $skill-installer，从 GitHub 仓库 liuhui199697-lang/my-skills 安装 skills/geometric-collage-poster 目录中的技能。

等待安装成功后，上传自己的图片，再发送：

> 请使用 $geometric-collage-poster，将这张图片转换为几何拼贴海报。

如果安装后没有识别到技能，请重启 Codex 再试。

此技能需要当前环境具备图像生成或编辑能力。安装技能本身不会增加图像工具。

### 更新技能

GitHub 上的修改不会自动同步到已下载或已安装的副本。

下载使用的用户可以重新下载最新文件；Codex 用户可以请 Codex 检查本仓库，并更新已安装的 geometric-collage-poster 技能。

### 风格说明

以纯色色块为主，允许轻微色调变化；保留必要的透视、遮挡和几何明暗层次。

默认“无文字”也会影响原图中的包装标签等文字，它们可能被概括为色带。如果需要保留文字，请在请求中明确说明。

输出通常为位图，不保证得到可编辑的矢量文件。效果可能随模型和输入图片变化，也可能出现局部纹理、渐变或构图偏移。
